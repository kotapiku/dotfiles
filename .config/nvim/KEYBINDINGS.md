# Neovim・LaTeX 操作とキーボードショートカット

この dotfiles のターミナル版 Neovim を中心に、設定ファイルに明示されている
キーマップと、LaTeX 執筆で使う主な標準キー・プラグインのキーをまとめています。
VS Code 専用の割り当ては末尾に分けています。

## キー表記とモード

- `\ll`：バックスラッシュ → 小文字の `l` → `l` と順番に押す。
- `Space hn`：スペース → `h` → `n` と順番に押す。
- `Ctrl+x` → `Ctrl+o`：それぞれを順番に押す。
- `Cmd`：Mac の Command キー。`Alt`：Option キー。`Ctrl`：Control キー。
- コマンドは標準の `:w` のように表記し、最後に `Enter` を押す。
  `;` と `:` のキー入れ替えはコマンド表記に反映しない。
- `Leader` と `LocalLeader` はどちらも `\`。

特に記載がなければノーマルモードの操作です。
挿入モードは文字を入力する状態、ビジュアルモードは文字を選択する状態です。
演算待ちは `d` や `y` などを押して、操作範囲の入力を待っている状態です。

## まず TeX をコンパイルして PDF を見る

ターミナルで原稿のディレクトリへ移動し、メインファイルを開きます。

```sh
cd /path/to/project
nvim main.tex
```

1. `Esc` でノーマルモードにする。
2. `:w` → `Enter` で保存する。
3. `\ll` で継続コンパイルを開始する。
4. 成功すると Skim で PDF が開く。手動で表示するには `\lv`。
5. 原稿を編集して保存すると、再コンパイルされて PDF が更新される。
6. PDF の本文を **`Cmd+Shift+クリック`** すると、編集中の Neovim で対応する行が開く。
7. 継続コンパイルを止めるには、もう一度 `\ll`、または `\lk`。

設定変更前から Neovim を開いている場合は、原稿を保存して再起動してください。

## 基本操作・保存・終了

標準キーも併記しています。「独自」はこの設定で変更している操作です。

| キー・入力 | モード | 操作 |
| --- | --- | --- |
| `i` / `a` | 通常 | カーソルの前／後から入力開始 |
| `v` / `V` | 通常 | 文字単位／行単位で選択開始 |
| `Esc` | 挿入・選択 | ノーマルモードへ戻る |
| `jk` | 挿入 | ノーマルモードへ戻る（独自） |
| `;` | 通常 | コマンド入力を開始。標準の `:` に相当（独自） |
| `:` | 通常 | 直前の `f`・`t`・`F`・`T` による移動を繰り返す。標準の `;` に相当（独自） |
| `:w` | 通常 | 保存 |
| `:q` | 通常 | 現在のウィンドウを閉じる。未保存の変更があれば止まる |
| `:wq` | 通常 | 保存して現在のウィンドウを閉じる |
| `u` / `Ctrl+r` | 通常 | 元に戻す／やり直す |
| `yy` | 通常 | 現在の行全体をコピー |
| `Y` | 通常 | カーソルから原稿の行末までコピー（独自） |
| `p` / `P` | 通常 | 後／前に貼り付け |

コピー・貼り付けはシステムのクリップボードと連携します。
永続 undo が有効なので、保存した編集履歴は Neovim の再起動後もたどれます。

## LaTeX：コンパイル・PDF・エラー

TeX バッファで有効です。`Ctrl+Alt+j` は独自設定、`\l…` は VimTeX の標準割り当てです。

| キー・入力 | 操作 |
| --- | --- |
| `\ll` | 継続コンパイルの開始・停止 |
| `\lk` | 現在の原稿のコンパイルを停止 |
| `\lK` | 全ての VimTeX プロジェクトのコンパイルを停止 |
| `:VimtexCompileSS` | 1回だけコンパイル |
| `\lv` / `Ctrl+Alt+j` | PDF を表示し、原稿の現在位置へ移動（順検索） |
| `\le` | コンパイルエラーを表示 |
| `\lo` | コンパイラの出力を表示 |
| `\li` / `\lI` | メインファイル・使用コマンドなどの情報／詳細情報 |
| `\lg` / `\lG` | 現在／全プロジェクトのコンパイル状態 |
| `\lq` | VimTeX 自体のログを表示 |
| `\lx` | VimTeX を再読み込み |

エラー一覧では、項目を選んで `Enter` を押すと該当箇所へ移動できます。
端末が `Ctrl+Alt+j` を認識しない場合も `\lv` で同じ操作ができます。

### Skim から原稿へ戻る

**Skim で `Cmd` と `Shift` を同時に押しながら PDF の本文をクリックします。**
`Cmd+クリック` だけでは逆検索になりません。編集中の Neovim は開いておいてください。
ターミナルが前面に出ない場合は、ターミナルに切り替えてカーソル位置を確認します。

Skim の設定 → Sync → PDF-TeX Sync は以下の Custom 設定です。

```text
Command:   /opt/homebrew/bin/nvim
Arguments: --headless -c "VimtexInverseSearch %line '%file'"
```

位置の対応には、コンパイル時に生成される `.synctex.gz` が必要です。
VimTeX の通常の latexmk 設定では SyncTeX を有効にしてコンパイルします。

### 分割原稿・コンパイル方式

分割ファイルの先頭では、必要に応じてメインファイルを相対パスで指定します。

```tex
% !TeX root = main.tex
```

エンジンはプロジェクトの `.latexmkrc` またはメインファイルの指定に従います。
LuaLaTeX を使う場合の指定例です。

```tex
% !TeX program = lualatex
```

## LaTeX：補完・数式入力・構造の編集

VimTeX の標準の割り当てを中心に、定義への移動もまとめています。

| キー | モード | 操作 |
| --- | --- | --- |
| `Ctrl+x` → `Ctrl+o` | 挿入 | 引用・ラベル・コマンドなどの補完 |
| `Ctrl+n` / `Ctrl+p` | 補完中 | 次／前の候補へ移動 |
| `Ctrl+y` / `Ctrl+e` | 補完中 | 候補を確定／補完をキャンセル |
| `]]` | 挿入 | 現在の環境・区切りを閉じる |
| `\lm` | 通常 | 数式入力用の省略キー一覧 |
| `\lt` / `\lT` | 通常 | 目次を開く／表示を切り替える |
| `gd` | 通常・TeX のみ | カーソル下のラベルなどの定義へ移動（独自。複数候補なら選択） |
| `Ctrl+t` | 通常 | タグ移動前の位置へ戻る |
| `[m` | 通常・選択・演算待ち | 直前の環境の開始 `\begin{…}` へ移動 |
| `[M` | 通常・選択・演算待ち | 直前の環境の終了 `\end{…}` へ移動 |
| `]m` | 通常・選択・演算待ち | 直後の環境の開始 `\begin{…}` へ移動 |
| `]M` | 通常・選択・演算待ち | 直後の環境の終了 `\end{…}` へ移動 |
| `%` | 通常 | `\begin`・`\end` などの対応する相手へ移動 |
| `\la` | 通常 | カーソル位置に応じたメニューを開く |
| `cse` | 通常 | 周囲の環境名を変更 |
| `dse` | 通常 | 周囲の環境の `\begin`・`\end` を取り除く |
| `csc` / `dsc` | 通常 | 周囲の LaTeX コマンドを変更／取り除く |
| `tse` | 通常・選択 | 環境の `*` 付き／なしを切り替える |
| `tsc` | 通常・選択 | コマンドの `*` 付き／なしを切り替える |
| `ts$` | 通常・選択 | インライン数式とディスプレイ数式を切り替える |
| `ie` / `ae` | 選択・演算待ち | 環境の内側／環境全体を操作範囲にする |
| `i$` / `a$` | 選択・演算待ち | 数式の内側／数式の区切りを含む範囲を指定 |

例えば `\ref{sec:` の中で `Ctrl+x` → `Ctrl+o` を押すとラベル候補が出ます。
ラベル補完は `.aux` を使うため、最初に一度コンパイルしてください。
`\cite{` の中でも同じキーで引用候補を選べます。

`\ref{...}` から定義へ移動するには、中のラベル名にカーソルを置いて `gd` を押します。
TexLab が接続済みなら解析結果を使い、候補がなければ `tags` ファイルを使います。
`tags` は TeX を開いたときになければ自動生成し、保存後に更新します。
Universal Ctags の導入と生成先は [README.md](README.md#tags-の自動生成) を参照してください。
`Ctrl+]` が端末の pane 操作と重なる場合も、`gd` で移動できます。

操作範囲の例：`vie` は環境の内側を選択、`ci$` は数式の内側を書き換えます。
環境移動は **`[`＝直前、`]`＝直後、`m`＝開始、`M`＝終了** と覚えます。
`2]m` のように回数も指定できます。移動先は条件に合う直近の境界なので、
入れ子がある場合は、今いる外側の環境の境界とは限りません。
数式の省略キーは通常の文字入力と区別され、一覧は `\lm` で確認できます。

## LaTeX：スニペット（LuaSnip）

挿入モードで略語を入力し、`Tab` で展開します。入力欄は `Tab` で次へ、
`Shift+Tab` で前へ移動します。選択状態の入力欄にはそのまま文字を入力できます。
スニペットを展開・移動できない場所では `Tab` は通常のインデント入力です。
補完メニューが開いている間は、`Tab` / `Shift+Tab` で次／前の候補を選びます。

| 略語 → `Tab` | 展開するもの | 使える場所 |
| --- | --- | --- |
| `ff` | `\frac{分子}{分母}` | 数式内 |
| `sq` | `\sqrt{中身}` | 数式内 |
| `sum` | `\sum_{i=1}^{n}` と続く式 | 数式内 |
| `int` | `\int_{a}^{b}` と被積分関数・積分変数 | 数式内 |
| `mk` | `$…$` | 本文 |
| `dm` | `\[ … \]` | 本文 |
| `ali` | `align*` 環境 | 本文 |
| `eq` | `equation` 環境と `\label{eq:name}` | 本文 |
| `env` | 任意の環境。開始側の環境名を入力すると終了側も更新 | 本文 |
| `itm` | `itemize` 環境と最初の `\item` | 本文 |

「本文」は数式・コメントの外です。自動展開はせず、`Tab` を押したときに展開します。
例えば `$ff` と入力して `Tab` を押すと分数になり、分子 → `Tab` → 分母の順に書けます。
定義は [tex_snippets.lua](lua/dotfiles/tex_snippets.lua) で追加・変更できます。

## LaTeX：折りたたみ

VimTeX が章・節・環境ごとに折りたたみ範囲を作ります。最初は全て表示されます。
折りたたみは画面上の表示だけを変え、原稿の内容には影響しません。

| キー | 操作 |
| --- | --- |
| `za` | カーソル位置の折りたたみを開閉 |
| `zc` / `zo` | 閉じる／開く |
| `zM` / `zR` | 全て閉じる／全て開く |
| `zx` | 編集後に折りたたみ範囲を再計算し、現在位置を表示 |

長い原稿でも入力のたびに再計算しない設定です。節や環境を追加して範囲がずれたら `zx`。

## LaTeX・BibTeX：定義・参照・名前変更（TexLab）

`.tex`・`.bib` を開くと Neovim 標準の LSP 機能で TexLab に接続します。
コンパイルと PDF 表示は、上記の VimTeX のキーを使います。
TeX の `Ctrl+x` → `Ctrl+o` は引き続き VimTeX の補完です。

| キー・コマンド | 操作 |
| --- | --- |
| `gd` | TeX 内でラベルなどの定義へ移動 |
| `Ctrl+t` | `gd` で移動する前の位置へ戻る |
| `grr` | カーソル下のラベルなどを参照している箇所を検索 |
| `grn` | ラベルなどの名前と対応する参照をまとめて変更 |
| `[d` / `]d` | 前／次の診断メッセージの場所へ移動 |
| `Ctrl+w` → `d` | カーソル行の診断メッセージを表示 |
| `:checkhealth vim.lsp` | TexLab の接続状態を確認 |

`grr`・`grn` は小文字を順番に押します。候補一覧では `Enter` で該当箇所へ移動します。
`grn` の変更は編集中のバッファに反映されるので、内容を確認してから保存してください。
`:wall` は開いている変更済みファイルをまとめて保存します。

診断は下線と行頭の記号で表示し、本文の横にはメッセージを常時表示しません。
接続直後は解析に少し時間がかかる場合があります。

## ファイル・行・履歴の検索（fzf）

[dein.toml](dein/toml/dein.toml) に設定しているキーです。大文字と小文字を区別します。

| キー | 操作 |
| --- | --- |
| `,f` | ファイルを探して開く |
| `,g` | Git 管理下のファイルを探して開く |
| `,F` | Git の変更状態一覧からファイルを選ぶ |
| `,b` | 開いているバッファから選ぶ |
| `,l` | 現在のバッファ内の行を検索 |
| `,L` | 開いている全バッファの行を検索 |
| `,h` | 最近開いたファイルから選ぶ |
| `,m` | マーク一覧から移動先を選ぶ |
| `Ctrl+]` | カーソル下の単語でタグを検索してジャンプ |

候補画面では文字を入力して絞り込み、`Enter` で決定、`Esc` で閉じます。
`Ctrl+]` のタグ検索には、あらかじめ生成した `tags` ファイルが必要です。
TeX の `tags` はファイルを開いたときになければ生成し、保存後に自動更新します。

## Git の変更箇所（vim-gitgutter）

Git 管理下のファイルで使う、プラグインの標準キーです。
変更のひとまとまりを「ハンク」と呼びます。

| キー | モード | 操作 |
| --- | --- | --- |
| `]c` / `[c` | 通常 | 次／前の変更箇所へ移動 |
| `\hp` | 通常 | 現在の変更箇所をプレビュー |
| `\hs` | 通常・選択 | 現在の変更箇所／選択した変更をステージする |
| `\hu` | 通常 | 現在の変更箇所を取り消し、作業中の変更を破棄する |

`\hp` とバッファ移動の `Space hp` は、最初に押すキーが異なります。

## バッファ切り替え

バッファは Neovim で開いているファイルです。全て独自設定です。

| キー | 操作 |
| --- | --- |
| `Space hn` | 次のバッファ |
| `Space hp` | 前のバッファ |
| `Space hb` | 直前に使ったバッファ |
| `Space hf` | 最初のバッファ |
| `Space hm` | バッファ一覧の中央付近へ移動 |
| `Space hl` | 最後のバッファ |
| `Space hd` | 前のバッファへ移動して元のバッファを閉じる |

## 原稿内の移動・検索・置換

| キー・入力 | モード | 操作 |
| --- | --- | --- |
| `j` / `k` | 通常・選択・演算待ち | 折り返しを含む画面上の1行下／上へ移動（独自） |
| `0` / `$` | 通常・選択・演算待ち | 画面上の行頭／行末へ移動（独自） |
| `gg` / `G` | 通常 | ファイルの先頭／末尾へ移動（標準） |
| `/検索語` → `Enter` | 通常 | 前方検索（標準） |
| `n` / `N` | 通常 | 次／前の一致箇所へ移動し、画面中央に表示（独自） |
| `gs` | 通常 | ファイル全体を対象にした置換コマンドの入力を開始（独自） |
| `gs` | 選択 | 選択した行を対象にした置換コマンドの入力を開始（独自） |
| `:nohlsearch` | 通常 | 検索結果の強調表示を一時的に消す（標準コマンド） |

`gs` は置換を即実行せず、検索語と置換後の文字列を入力できる状態にします。
ビジュアルモードでの置換範囲は、選択した文字だけではなく、その文字を含む行です。

確認しながら全体を置換する例。次のコマンドを入力して `Enter`。

```vim
:%s/置換前/置換後/gc
```

確認時は `y` で置換、`n` でスキップ、`q` で終了します。

## クリップボードの内容で置き換える

以下は独自設定です。対象部分を消してクリップボードの内容を挿入し、
ノーマルモードに戻ります。消した文字列でクリップボードを上書きしません。

| キー | 置き換える対象 |
| --- | --- |
| `\rw` | カーソル位置の単語 |
| `\r"` | `"…"` の内側 |
| `\r'` | `'…'` の内側 |
| `\r(` | `(…)` の内側 |
| `\r[` | `[…]` の内側 |
| `\r{` | `{…}` の内側 |

例えば `\ref{old-label}` の中にカーソルを置いて `\r{` を押すと、
中の `old-label` をクリップボードの文字列に置き換えます。括弧自体は残ります。

| キー | 操作・例 |

### 括弧の自動入力（doorboy）

挿入モードでは、`(`・`[`・`{` や引用符を入力すると、状況に応じて閉じ側も補います。
閉じ括弧がすぐ後ろにあるときに同じ括弧を入力すると、その外へ移動します。
空の括弧内の `Space`・`Backspace`・`Enter` も、空白・括弧の削除・改行を補助します。

## 設定ファイルを開くコマンド

全て独自コマンドです。ノーマルモードで入力し、最後に `Enter` を押します。

| 入力 | 開くもの |
| --- | --- |
| `:Vimrc` | `~/.vimrc` |
| `:Zshrc` | `~/.zshrc` |
| `:Tmuxconf` | `~/.tmux.conf` |
| `:Deintoml` | 通常読み込むプラグインの設定 |
| `:DeintomlLazy` | 遅延読み込みするプラグインの設定 |

この一覧を Neovim で開くには、`:e ~/.config/nvim/KEYBINDINGS.md` → `Enter`。

## Coq 用の設定

LaTeX とは別に、[dein_lazy.toml](dein/toml/dein_lazy.toml) に Coq 用の設定が残っています。
利用には coquille と対応する Coq・Python 環境が必要です。この環境での実行は未検証です。

| キー | モード・条件 | 設定されている操作 |
| --- | --- | --- |
| `Ctrl+s` | Coq プラグイン読み込み後・通常 | カーソル位置まで証明を進める（`CoqToCursor`） |
| `F2` | Coq 用関数キーマップ・通常／挿入 | 1ステップ戻す（`CoqUndo`） |
| `F3` | Coq 用関数キーマップ・通常／挿入 | 次へ進める（`CoqNext`） |
| `F4` | Coq 用関数キーマップ・通常／挿入 | カーソル位置まで進める（`CoqToCursor`） |

`Ctrl+s` は保存用には設定されていません。また、この Coq 用割り当てには
バッファ限定の指定がないため、読み込み後は他のバッファでも有効になります。

## VS Code 用の追加割り当て

別ファイル [.vimrc_vscode](../../.vimrc_vscode) を読み込む構成向けです。
ターミナル版 Neovim の追加キーではありません。
共通する `Space h…`・`gs`・`\r…` などに加えて、以下が記述されています。

| キー | モード・条件 | 設定されている操作 |
| --- | --- | --- |
| `Ctrl+a` → `r` | VS Code・通常 | VS Code ウィンドウを再読み込み |
| `Ctrl+w` → `x` | VS Code・通常 | エディターとエディターグループを閉じる |
| `ae` | VS Code・選択／演算待ち | LaTeX Workshop の機能で環境の内容を選ぶ |
| `i$` | 選択／演算待ち | `$…$` の内側を操作範囲にする独自定義 |

VS Code と LaTeX Workshop 側の機能が必要なキーは、それらの拡張機能が有効な場合に使います。

## 困ったとき・割り当ての調べ方

| 状況 | 確認すること |
| --- | --- |
| 保存してもコンパイルされない | `\lg` で状態を確認し、停止中なら `\ll` |
| コンパイルエラー | `\le` でエラー、`\lo` で出力を見る |
| 別のファイルがコンパイルされる | `\li` と `% !TeX root` を確認 |
| PDF が開かない | コンパイル成功を確認して `\lv`。`\li` でビューアー設定も確認 |
| PDF から原稿へ戻れない | `Cmd+Shift+クリック`、Skim の Sync 設定、編集中の Neovim を確認 |
| PDF と原稿の位置が合わない | 保存して再コンパイルし、PDF と `.synctex.gz` を更新 |
| ラベル補完が出ない | 一度コンパイルして `.aux` を生成 |

Neovim 内では、以下のコマンドで実際の割り当てと設定元を調べられます。
ファイルの種類による上書きも確認できます。

| 入力 | 確認するもの |
| --- | --- |
| `:verbose nmap` | ノーマルモードの割り当て一覧と設定元 |
| `:verbose imap` | 挿入モードの割り当て一覧と設定元 |
| `:verbose xmap` | ビジュアルモードの割り当て一覧と設定元 |
| `:verbose tmap` | ターミナルモードの割り当て一覧と設定元 |
| `:verbose nmap \lv` | `\lv` の割り当てと設定元 |
| `:help vimtex-default-mappings` | VimTeX 標準キーの全一覧 |
| `:help sandwich` | 囲みの編集のヘルプ |

設定の構成・復旧・更新方法は [README](README.md) を参照してください。
